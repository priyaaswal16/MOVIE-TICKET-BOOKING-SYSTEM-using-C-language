# Movie Ticket Booking System in C

A console-based Movie Ticket Booking System developed using C programming during my 2nd semester.

## Features
- User registration and login
- Display available movies and show timings
- Seat selection and ticket booking
- Calculate the total ticket price
- View bookings for the logged-in user
- File handling to save and load user and booking records

## Concepts Used
- C Programming
- Structures and Arrays
- Functions
- File Handling
- String Manipulation
- Loops and Conditional Statements

## Learning Objective
This project helped me practise C programming fundamentals and understand how to build a simple menu-driven application.


## Note
This is a beginner-level learning project. User credentials are stored in plain text, so it is not intended for production use.
